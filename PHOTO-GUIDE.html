Photo and asset replacement guide

Open index.html for the website. This guide identifies each asset by thumbnail, filename, purpose and pixel dimensions.

To replace a photo, save the replacement with exactly the same filename, extension and folder location. Keep the same proportions. For moving accessories and the logo, use a transparent PNG with the same canvas size. The checkerboard in this guide shows transparency.

Production photos have two versions. Replace the gallery image and its matching full-size original if you want both the thumbnail and enlarged view to change. The first three gallery images are retouched.

Catalogue covers and PDF documents are separate files. Replace both when updating a catalogue. Certificate pictures are summary images. The location pins and contact text are in index.html. CSS controls layout and animation.
